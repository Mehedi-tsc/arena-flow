# ArenaFlow — Smart Sports Facility Booking Platform

## Purpose:
ArenaFlow is a smart sports facility booking platform where users can easily explore and book sports venues like football turfs, badminton courts, swimming pools, and tennis courts for specific dates and time slots. The goal of this project is to provide a simple and user-friendly sports reservation experience.

## Live URL:
* Client Side: https://arena-flow-five.vercel.app
* Server Side: https://arena-flow-server.vercel.app

## Key Features:
* Authentication & Authorization using Better Auth
* User Registration & Login System
* Browse All Facilities
* Search Facilities by Name  
* Filter Facilities by Category
* Add New Facilities
* Update Facility Information
* Book Facilities with Date & Time Slots
* Fully Responsive Design
